# 2026-11-25 控制台焦點修正

## 問題

- 放映開始後勾選「放映時控制台不搶焦點」，把焦點切到桌面再點擊控制台，控制台無法取得焦點。
- 因為控制台沒有焦點，`Window_PreviewKeyDown` 收不到方向鍵，←／→ 無法翻頁。
- 翻頁筆走 Raw Input、資料夾選擇是滑鼠對話框，所以這兩個功能看起來正常。

## 根因

`ApplyConsoleActivation()` 在放映中對主視窗套用 `WS_EX_NOACTIVATE`。

Windows 對這個 extended style 的定義是：

- 使用者用滑鼠點擊視窗時，視窗不會成為前景視窗。
- 但程式可用 `SetForegroundWindow` 強制激活。

所以出現「點擊無效、Alt+Tab 或快速鍵可以切回」的現象。

## 修正

1. 主控制台不再套用 `WS_EX_NOACTIVATE`。
2. 「不搶焦點」只保留為「程式不主動把焦點從放映視窗搶走」：放映開始時仍把前台交還放映視窗。
3. 主視窗加入 `PreviewMouseDown`，使用者主動點擊時確保取回焦點。
4. 方向鍵導航增加日誌：`鍵盤方向鍵 → 下一頁／上一頁`，方便現場排查。

## 驗證

- Debug 建置通過：`ProjectionManager -> bin\Debug\net8.0-windows\ProjectionManager.dll`。
- 需在雙螢幕＋PowerPoint 放映環境驗證：
  1. 勾選「放映時控制台不主動搶焦點」。
  2. 點桌面，再點控制台，標題列應正常激活。
  3. 按 ←／→，日誌應出現 `鍵盤方向鍵 → ...`，投影應切頁。
