Glory 榮耀 · 投影控制台 V2.3
快速開始（安裝前請先讀）

一、這個安裝包包含什麼
1. Glory 榮耀投影控制台 V2.3 主程式。
2. .NET 8 桌面執行環境，目標電腦不需要另外安裝 .NET。
3. Microsoft Edge WebView2 離線執行環境，用於網頁投影。
4. 繁體中文操作手冊（DOCX 與 PDF）。
5. 本次更新與實機測試重點。

二、安裝前確認
1. 作業系統為 Windows 10 或 Windows 11，64 位元。
2. 主 PPT 放映需要目標電腦已安裝 Microsoft PowerPoint 2016 或更新版本；安裝包不包含 Office。
3. 建議接上第二螢幕或投影機，並在 Windows「顯示設定」設為「延伸」。
4. 手機控制需要電腦與手機在同一個 Wi-Fi 區網，Windows 防火牆允許 TCP 5180；若 Wi-Fi 被判定為「公用網路」，也要允許。

三、安裝步驟
1. 雙擊安裝包。若出現 SmartScreen，選擇「更多資訊」再按「仍要執行」。
2. 依精靈完成安裝。安裝過程會自動檢查並安裝 WebView2，可能需要幾分鐘。
3. 安裝完成後，桌面會出現「Glory 榮耀 · 投影控制台」捷徑。
4. 第一次啟動前，先確認第二螢幕能顯示桌面。

四、現場操作
1. 啟動程式，右上角「設定」可選黑金、深灰青綠、暖白三種主題。
2. 主 PPT：按「加入主 PPT」選取簡報，確認放映目標後按「開始放映」。
3. 素材：在左側選素材，確認頁碼後按「推送投影」；未按推送不會上投影幕。投影中同一按鈕會變成「斷開投影」。
4. 經文／網頁：先按「+ 經文」或「+ 網頁」加入並選取內容，再按「推送投影」；與素材流程一致。
5. 分組：未指定分組的素材進入「默認分組」；可用左欄搜尋框按名稱或分組關鍵字定位素材。
6. 手機控制：按「手機控制...」啟動服務，手機連同一個 Wi-Fi，輸入畫面上的網址與配對碼。
7. 手機可開始／結束主 PPT 放映、上下頁、跳頁、黑屏、恢復，以及對素材／經文／網頁／Zoom 執行「推送投影／斷開投影」。
8. 手機投影源選單按分組折疊顯示，上方有搜尋框；可在手機上直接找素材，不必關閉視窗重進。

五、操作日誌與故障排查
1. 日誌位置：%LocalAppData%\Glory\logs\glory-YYYYMMDD.log
2. 日誌包含啟動版本、系統資訊、投影操作與錯誤堆疊。
3. 發生問題時，開啟「設定」→「匯出診斷包」，桌面會產生 ZIP；把 ZIP 交給技術支援。
4. 詳細操作、常見問題與實機測試清單，請看 docs 資料夾內的操作手冊與本次更新說明。

Glory 榮耀投影控制台 V2.3.0

七、已知限制
1. 主 PPT 放映依賴本機 PowerPoint。
2. 網頁投影依賴 WebView2；安裝包已附離線安裝程式。
3. 單螢幕僅能在控制台預覽，無法真正投出到第二螢幕。
4. 手機控制需要同一個區網；跨網段、AP 隔離或訪客網路可能無法連線。
